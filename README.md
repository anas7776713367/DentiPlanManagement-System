# DentiPlanManagement-System
EN: A C++ Dental Clinic Management System using Linked Lists and Queues. Features include appointment scheduling, an automated waiting list, and data persistence via file handling.

نظام إدارة عيادة الأسنان (Dental Clinic Management System)
تطبيق متكامل بلغة ++C لإدارة مواعيد المرضى بكفاءة عالية، يجمع بين السرعة في الأداء وتنظيم البيانات باستخدام هياكل بيانات متقدمة.

✨ المميزات الرئيسية (Key Features)
حجز المواعيد: إضافة مرضى جدد مع التأكد من عدم تضارب الأوقات.

قائمة الانتظار الذكية: في حال كان الوقت محجوزاً، يتم نقل المريض تلقائياً لقائمة الانتظار.

تحديث المواعيد التلقائي: عند إلغاء موعد، يقوم النظام بسحب أول مريض من قائمة الانتظار ووضعه في الموعد المتاح.

ديمومة البيانات (File Handling): يتم حفظ جميع البيانات في ملف نصي (appointments.txt) لضمان عدم ضياعها عند إغلاق البرنامج.

البحث السريع: إمكانية البحث عن موعد مريض محدد بالاسم.

🏗️ هياكل البيانات المستخدمة (Data Structures)
تم بناء المشروع باستخدام مفاهيم برمجية متقدمة لضمان الكفاءة:

Linked List (القوائم المرتبطة): لإدارة المواعيد الأساسية بشكل ديناميكي ومرن.

Queue (الطابور): بنظام (FIFO - First In First Out) لإدارة قائمة الانتظار لضمان العدالة في الأولوية.

Structs (الهياكل): لتمثيل بيانات المريض (الاسم، الهاتف، الوقت) ككتلة واحدة.

🚀 كيفية التشغيل (How to Run)
قم بتحميل ملف main.cpp.

استخدم أي مترجم لغة ++C (مثل Dev-C++ أو Visual Studio).

قم بتشغيل البرنامج، وسيتم إنشاء ملف الحفظ تلقائياً في نفس المجلد.
